# Sécurité / Security

Si vous découvrez une faille de sécurité sur virall.art ou dans ce dépôt, merci de ne pas ouvrir de ticket public. Écrivez à **contact@virall.art** en décrivant le problème et la façon de le reproduire. Nous répondons sous 5 jours ouvrés.

If you find a security issue on virall.art or in this repository, please do not open a public issue. Email **contact@virall.art** with a description and steps to reproduce. We reply within 5 business days.

Le site est statique : il n'a ni base de données, ni compte utilisateur, ni clé d'accès.
The site is static: no database, no user accounts, no secrets.
